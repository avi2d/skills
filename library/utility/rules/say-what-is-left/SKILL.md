# Say what is left

Never size work in days, weeks, hours, sprints, story points, or size words that stand for them, such as "small" or "medium". Those figures come from how long people take, and nothing you can observe backs them. This holds for your own work, for work you plan for other agents, and for every option in a comparison.

Say these instead:

- **What is left.** The remaining steps or pull requests, counted and named, each with the check that ends it.
- **What waits on the person.** Every decision, approval, credential or review the work needs from them, and the step each one holds. Ask for them together when you can.
- **What could grow it.** The unknowns you can name, and the first check that settles each.

Give a duration only when you read it from a record: the measured time of comparable finished work, a run you timed, or a date someone else set. State it as a range, name the record and how many comparable cases it rests on, and count failed and dropped tasks, not only successes. Agent run time that overlaps other work is not added up as calendar time. Keep time spent working apart from time spent waiting. When the sample is too small or too different, or no record exists, say so and give no number.

When the person asks how long, answer with the count of steps, what waits on them, and a recorded range when you have one.
